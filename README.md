# Villa Manager (Vanilla JS)

Pequeña interfaz para gestionar reservas, itinerario y lista de compras.

Archivos principales:
- `villa-manager.html`  Interfaz autocontenida (HTML + CSS + JS).

Cómo usar:
1. Abrir `villa-manager.html` en tu navegador (doble clic o arrastrar a la ventana del navegador).
2. Buscar, filtrar y hacer clic en una tarjeta para ver el panel lateral.

Siguientes ideas:
- Separar HTML/CSS/JS en archivos (`index.html`, `styles.css`, `script.js`).
- Inicializar un repositorio remoto (GitHub) y configurar CI/CD.
